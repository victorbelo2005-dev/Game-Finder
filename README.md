# 🎮 GameFinder

Busca de jogos free-to-play com detalhes e descrição traduzida pro português.

🔗 **Demo:** https://victorbelo2005-dev.github.io/gamefinder/

## Funcionalidades
- Busca de jogos por nome
- Cards com capa, gênero, plataforma e data de lançamento
- Modal com detalhes do jogo
- Descrição traduzida automaticamente (com cache)
- Estados de carregando, erro e "nenhum jogo encontrado"
- Layout responsivo

## Tecnologias
HTML5, CSS3 (Grid, variáveis CSS) e JavaScript puro (fetch, async/await, DOM)

## Como rodar
1. Clone o repositório
2. Abra o `index.html` (ou use a extensão Live Server do VS Code)

## Créditos
- Dados de jogos: [FreeToGame.com](https://www.freetogame.com)
- Tradução: API MyMemory
